## Local LLM Plugin 4.0 — Liquid Glass

A ground-up refresh of the AI assistant for Visual Studio: a new macOS-inspired interface, live streaming from every provider, conversations, quick actions and a much safer editor integration.

![AI Assistant](https://raw.githubusercontent.com/furkiak/visualStudioLocalLLMPlugin/master/docs/images/assistant-dark.png)

### ✨ Highlights

- **Liquid Glass interface** — glass surfaces, capsule buttons, traffic-light window controls and an animated glow while the model writes. Dark and light themes follow your Visual Studio theme; Windows 11 acrylic blur behind the window.
- **Live streaming** for Ollama, LM Studio / OpenAI-compatible servers, OpenAI, Anthropic and Google Gemini. **Esc** stops an answer instantly.
- **Conversations** with follow-up questions, **Regenerate** and **Use as input**.
- **Quick actions** — Explain, Refactor, Fix bugs, Optimize, Document, Unit tests, Review.
- **Markdown answers** with code cards (Copy / Apply) and a separate *Thought process* for reasoning models.
- **Smarter apply** — only code is inserted, indentation is matched, line endings are kept and everything is one **Ctrl+Z**. New **Insert below** (Ctrl+Shift+Enter) and partial apply.
- **Settings** — per-provider profiles, model list (↻), connection test, theme and translucency options.
- **Security** — API keys are encrypted with Windows DPAPI; the Gemini key is sent in a header, not in the URL.
- **Six new text tools** — sort, reverse, remove empty lines, trim trailing whitespace, upper/lower case.
- **Visual Studio 2026 and Arm64** support, and an editor right-click menu entry.

### 🐞 Fixes

- Visual Studio could crash when a request failed; the busy state could get stuck.
- Shift+Enter could insert “AI Thinking…” or an error message into your code.
- Local models were cut off after 100 seconds (now an adjustable idle timeout; long answers are never cut).
- `localhost` endpoints were ignored for OpenAI/Anthropic, so local OpenAI-compatible servers could not be used.
- Switching providers carried the previous provider's API key over.
- Text tools dropped the final line break of the selection; *Remove duplicates* deleted blank lines.
- Enter sent the prompt while editing the code box; Ctrl+Enter did not insert a new line.
- A corrupt settings file broke the extension; applying to a non-text document crashed.

### ⬆️ Upgrading

Install the `.vsix` below (or update from the Visual Studio Marketplace) and restart Visual Studio. Settings from 3.x — including your API key — are migrated automatically.

**Requirements:** Visual Studio 2022 17.0+ or Visual Studio 2026 (Community, Professional, Enterprise), x64 or Arm64.
