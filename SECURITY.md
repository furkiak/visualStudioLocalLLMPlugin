# Security reporting and boundaries

Report a suspected vulnerability privately through GitHub's **Security → Report a vulnerability** if that facility is enabled for this repository. If unavailable, use the maintainer's contact route at https://furkiak.com to request a private channel before sending reproduction details. Do not include API keys, proprietary source or a working exploit in a public issue.

The extension sends the displayed selection and instruction to the configured endpoint. A loopback endpoint may itself forward data. Cloud-provider retention and billing follow that provider's policy. There is no automatic secret detector or automatic repository-wide collection.

DPAPI CurrentUser protects the stored API key under the current Windows profile. It does not protect a key from code already running as that user, an administrator, a compromised endpoint, process memory or pre-existing backups of old plaintext settings. The model and URL are not encrypted. Credentials in URLs are rejected. Previously exposed keys should be rotated at their provider.

Treat generated code as untrusted suggestions. Review the whole candidate before applying it. The extension does not compile, execute or prove the safety of generated code. Keep source under version control.
